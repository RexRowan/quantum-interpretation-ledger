# Database

This repo does not vendor the experiment/proposal bibliography. It's
maintained separately in [Experimental-Tests-of-Quantum-Interpretations](https://github.com/RexRowan/quantum-interpretation-ledger/blob/main/db/README.md) and referenced
by entry when a falsification hypothesis is formalized.

Each falsification theorem's comment should cite the specific survey
entry (author/year or bibliography key) it draws its experimental
hypothesis from, so the logical claim and the empirical claim stay
traceable to two different, independently reviewable places.
