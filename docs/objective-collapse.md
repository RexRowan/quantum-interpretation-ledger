# Objective collapse (GRW / CSL / Diósi-Penrose)

Migrated in full from `Experimental-Tests-of-Quantum-Interpretations`, which
has since been reduced to a standalone interactive demo
([live demo](https://spectacular-starship-358260.netlify.app/)). This file
is now the canonical reference copy; it mirrors `Ledger/ObjectiveCollapse.lean`
exactly.

Objective collapse models are the one interpretation family that actually
modifies the Schrödinger equation, which is what makes them the one place
"interpretation" work turns into an experimental physics program.
Many-worlds, Bohmian mechanics, QBism, relational QM, and
Copenhagen-without-collapse all predict identical statistics to unitary QM
and have no entry in the falsifiable tables below.

## The falsifiable branch

| Claim | Postulate | Dataset / observatory | Status | Reference |
|---|---|---|---|---|
| Dey-Barker-Datta Coulomb squeezing bound | CSL's λ produces detectable decoherence via Coulomb-mediated squeezing between two levitated nanospheres | Levitated nanosphere pair, Coulomb-coupled | open | arXiv:2604.21705 |
| Reversible Nanoparticle Pointer | CSL predicts irreversible visibility loss that ordinary QM doesn't | Ramsey interferometry on levitated nanoparticle | open | arXiv:2606.22707 |
| Experimental Blueprint | Collapse-induced decoherence is separable from environmental noise via a Bayesian protocol | Proposed Bayesian analysis pipeline | open | arXiv:2512.02838 |
| Diósi-Penrose vs. GIE | Detecting gravitationally induced entanglement falsifies DP dynamics | Proposed GIE detection experiments | open — live, unresolved dispute | Phys. Rev. D 111, L121101 (2025) |

## No-go theorems and consistency checks

Constrain interpretations but don't themselves discriminate collapse vs. unitary evolution.

## Not experimentally distinguishable (completeness only)

- **Bohmian trajectory visualizations** (Kocsis et al. 2011, Mahler et al.
  2016, Foo et al. 2022) — reconstruct trajectories via weak measurement; a
  way to *see* Bohmian mechanics, not a way to test it against anything else.
- **QBism, relational QM, consistent histories** — no experimental section,
  for the same reason: there isn't one.
